# 🚀 Featured Project

## 01. Dual Dependency Gap — Egypt’s Import Dependency & Trade Risk Analysis

![Egypt's Import Dependency Dashboard](Egypt%E2%80%99s%20Import%20Dependency.png)

### Project Overview

An analytical project investigating Egypt’s import dependency and exposure to external trade disruptions, with a focus on the effects of the Russia–Ukraine war on selected commodity imports.

The project explores how supplier concentration and changes in international trade can affect import resilience, helping turn complex trade data into a clearer picture of potential economic vulnerabilities.

### 🎯 Business Questions
- How dependent is Egypt on selected international suppliers?
- How did import patterns change before and after February 2022?
- Which commodity groups are important when assessing import concentration?
- How can trade data help identify potential supply-chain vulnerabilities?

### 🔍 Analytical Approach
- Analyzed historical trade data covering **2019–2025**.
- Compared trade patterns before and after the Russia–Ukraine war began in February 2022.
- Examined selected food grains, fertilizers, and iron and steel imports.
- Explored supplier concentration and import dependency, including the Herfindahl–Hirschman Index (HHI) as a concentration-analysis method.
- Designed Power BI visualizations to make trade patterns and potential risks easier to explore.

### 🛠️ Tools & Skills
**Power BI** · **Power Query** · **DAX** · Data Modeling · KPI Development · Trade Data Analysis · Data Visualization

### 💡 Project Value
Demonstrates how data analytics and business intelligence can be applied to a real-world economic question: understanding import dependency and assessing exposure to external shocks.
