# Sales Data Analysis Dashboard

## Project Overview
This project uses Microsoft Power BI to visualize sales performance and explore business data across multiple cities, products, managers, and payment methods.

## Key Performance Indicators
- **Total Revenue:** 769.52K
- **Total Quantity:** 117.00K
- **Total Orders:** 254

## Dashboard Analysis
- **Payment Methods:** Shows the distribution of cash, credit card, and gift card payments.
- **Monthly Sales:** Tracks sales trends throughout the year.
- **Sales by City:** Compares sales performance across Berlin, Lisbon, London, Madrid, and Paris.
- **Sales by Manager:** Compares sales contributions by manager.
- **Online Revenue:** Displays revenue from online purchases.
- **Interactive Filters:** Enables filtering by payment method, city, and product.

## Tools Used
- Microsoft Power BI
- Data Visualization
- KPI Reporting
- Business Intelligence
